# 🔢 Sorting Visualizer (Java + Swing)

A desktop-based Sorting Visualizer built with **Java** and **Swing**.  
It demonstrates the working of popular sorting algorithms through animated bar visualizations in a user-friendly graphical interface.

## 🚀 Features

- Visualizes multiple sorting algorithms:
  - 🟢 Bubble Sort
  - 🔵 Selection Sort
  - 🟣 Insertion Sort
  - 🟠 Merge Sort
  - 🔴 Quick Sort
  - 🟡 Heap Sort
- Real-time bar animations showing comparisons and swaps
- Adjustable array size and sorting speed
- Interactive GUI built with Java Swing
- Highlights sorted elements and transitions clearly

## 🛠️ Tech Stack

- **Java**
- **Java Swing** for GUI components
- **Multithreading** for smooth animation and non-blocking UI
