# 🔢 Sorting Visualizer (Java + Swing)

A desktop-based Sorting Visualizer built with **Java** and **Swing**.
It demonstrates the working of popular sorting algorithms through animated bar visualizations in a user-friendly graphical interface, now with enhanced interactivity.

## 🚀 Features

* **Multiple Sorting Algorithms Visualized:**
    * 🟢 Bubble Sort
    * 🔵 Selection Sort
    * 🟣 Insertion Sort
    * 🟠 Merge Sort
    * 🔴 Quick Sort
    * 🟡 Heap Sort
    * 
* **Real-time Bar Animations:** Visualizes comparisons and swaps directly on the bars.
    * **Highlighting:** Elements being compared (Yellow), swapped (Red), pivot (Magenta), and sorted (Dark Green/Light Gray).
* **Adjustable Array Size:** Dynamically change the number of elements in the array using a slider without flickering.
* **Adjustable Sorting Speed:** Control the animation speed with a dedicated slider.
* **Pause/Resume Functionality:** Take control of the animation flow to observe steps closely.
* **Algorithm Information:** Displays the name and Big O complexity of the currently selected algorithm.
* **Live Counters:** Tracks and displays the total number of swaps and comparisons performed by the algorithm.
* **Full-Screen Display:** The application opens in a maximized window for a better visualization experience.
* **Interactive GUI:** Built entirely with Java Swing, offering a clean and responsive user experience.

## 🛠️ Tech Stack

* **Java**
* **Java Swing:** For all GUI components and rendering.
* **Multithreading:** Ensures smooth animation and a non-blocking user interface.

## 💻 How to Run

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/yourusername/sorting-visualizer-java.git](https://github.com/yourusername/sorting-visualizer-java.git)
    cd sorting-visualizer-java
    ```
    (Replace `yourusername/sorting-visualizer-java` with your actual GitHub repository path if it's different).

2.  **Compile the Java code:**
    Open your terminal or command prompt, navigate to the project directory, and compile the Java file:
    ```bash
    javac SortingVisualizer.java
    ```

3.  **Run the application:**
    After successful compilation, run the application:
    ```bash
    java SortingVisualizer
    ```
